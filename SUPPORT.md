# Support

- Read `README.md` and `docs/GETTING_STARTED.md` first.
- Use GitHub Discussions for setup questions and interpretation when enabled.
- Use the bug-report issue form for a reproducible harness defect.
- Use the benchmark-proposal form for task, grader, or scoring changes.
- Follow `SECURITY.md` for vulnerabilities; never post them publicly.

Support is community-based and best effort. Model-server setup, hardware tuning,
provider billing, and third-party Codex behavior remain the responsibility of those
projects. Always remove credentials and private model content from diagnostics.
